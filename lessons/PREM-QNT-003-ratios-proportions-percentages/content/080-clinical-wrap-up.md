# Clinical wrap-up: name the denominator before you draw up the dose

A clinician must draw up an illustrative dose from a stock solution, then say what fraction of a vial that dose represents. The percentage is meaningless until the denominator—the reference that defines 100 percent—is named.

**Teaching example—not medical advice.** The scenario and every number below are invented for ratio and percentage practice. They must not guide care or be used as a prescription.

## 1. Read the concentration as an ordered ratio

The invented stock concentration is $25\text{ mg}:1\text{ mL}$, read as 25 milligrams per millilitre. Keep the labels and order attached: this is not a bare “25.”

## 2. Follow one constant multiplier

The illustrative target is $10\text{ mg}$. To change $25\text{ mg}$ into $10\text{ mg}$, multiply by $\dfrac{10}{25}=0.4$. Apply the same multiplier to $1\text{ mL}$, giving $0.4\text{ mL}$.

The proportion records that equal-ratio scaling:

$$\frac{25\text{ mg}}{1\text{ mL}}=\frac{10\text{ mg}}{x\text{ mL}}\quad\Rightarrow\quad x=\frac{10}{25}=0.4\text{ mL}.$$

## 3. Verify by substitution

Substitute the result into the stock concentration:

$$
25\text{ mg/mL}\times 0.4\text{ mL}=10\text{ mg}.
$$

Both the value and the units return the target, so the proposed volume passes the check.

## 4. Name the denominator that means 100 percent

Suppose the invented vial contains $50\text{ mg}$. With **vial content** as the denominator, the dose is $\dfrac{10\text{ mg}}{50\text{ mg}}\times100\%=20\%$ of the vial.

Change the reference and the percentage changes. With **syringe capacity** as the denominator, $0.4\text{ mL}$ in a $10\text{ mL}$ syringe is $\dfrac{0.4\text{ mL}}{10\text{ mL}}\times100\%=4\%$ of that capacity. The dose is unchanged; the reference for 100 percent is different.

## Sanity check: percent change is not percentage points

If the invented protocol trims the dose from $10\text{ mg}$ to $8\text{ mg}$, the starting dose is the denominator: $\dfrac{10-8}{10}\times100\%=20\%$ decrease. It is not a 2 percent change, and it is not 2 percentage points; percentage points compare two percentages.

The arithmetic is correct for these invented figures only. It is not a real prescription.

:::{check}
:id: check-clinical-reference-choice

Before reading the feedback, explain why the same illustrative dose is 20% of the vial content but 4% of the syringe capacity.

**Feedback after an attempt:** The numerator describes the same dose in each comparison, but the denominator that represents 100% changes. Vial content and syringe capacity answer different part-whole questions, so their percentages need not match.
